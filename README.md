This project applies machine learning and data analytics to uncover actionable insights from a retail dataset provided by Imtiaz Mall. It involves extensive data cleaning, exploratory data analysis, and the application of regression, K-means clustering, and decision trees to model customer behavior and optimize sales strategies. Using Python libraries such as pandas, scikit-learn, and matplotlib, the project visualizes product performance and customer segmentation. Statistical modeling is employed to identify factors influencing purchasing trends. This structured pipeline enables enhanced business decision-making and marketing effectiveness. A comparative analysis of model accuracy and feature significance supports the choice of algorithms. The project provides a practical understanding of consumer behavior modeling, making it essential for real-world retail analytics applications.
